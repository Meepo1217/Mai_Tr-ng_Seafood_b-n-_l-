# Mai Trọng Seafood

Nền tảng thương mại điện tử chuyên cung cấp hải sản tươi sống trực tuyến, giao hàng tận nơi.

## Các công nghệ sử dụng
- **Framework**: Next.js 16 (App Router)
- **UI/Styling**: Tailwind CSS v4, Lucide React
- **State Management**: React Context (CartContext)
- **Ngôn ngữ**: TypeScript

## Cài đặt & Chạy dự án

1. Cài đặt các thư viện:
```bash
npm install
```

2. Chạy môi trường phát triển (Dev server):
```bash
npm run dev
```

Truy cập `http://localhost:3000` để xem website.

## Tính năng
- Trang chủ (Banner, Sản phẩm mới, Danh mục nổi bật, Bán chạy, Flash sale)
- Giỏ hàng & Thanh toán
- Lựa chọn phương thức giao hàng (Giao tận nơi hoặc nhận tại cửa hàng)
- Tìm kiếm & Lọc sản phẩm
- Giao diện Responsive hoàn thiện (Mobile / Desktop)
